# Order Management & Digital Wallet System

A production-grade backend system built with Java 21, Spring Boot, MySQL, Redis, Kafka, and Docker.

## Tech Stack
* **Language**: Java 21
* **Framework**: Spring Boot
* **Database**: MySQL 8+ / Hibernate JPA
* **Cache**: Redis
* **Message Broker**: Apache Kafka
* **Security**: Spring Security & JWT (Stateless)
* **Documentation**: OpenAPI 3 / Swagger UI
